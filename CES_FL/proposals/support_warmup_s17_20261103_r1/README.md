## Exact mathematics

Let m_gc be the mean soft FPR/FNR in auxiliary groupg/classc, using the SAME sigmoid((z−t_TRAIN)/temperature), temperature1, and detached natural-TRAIN-real threshold as before. TRAIN population class-conditioned priors are p_gc=N_gc/sum_h N_hc. Let rho_gc=U_gc/n_gc, where U is the number of distinct normalized (recorded identity IDs, recorded source IDs) tuples in that sampled TRAIN cell; missing IDs fall back to image path. This is recorded-tuple diversity, not verified biological independence. With n=4, rho is1/4,1/2,3/4 or1.

```
b_c = stopgrad(sum_g p_gc * m_gc)
L_upper = 2 * mean_gc rho_gc * max(0, m_gc - b_c)
a_epoch = 1                          # E
          min(1, (epoch+1)/3)        # F, epoch is absolute zero-based epoch
```

Replace only the old abs(m_gc−sum_h p_hc*m_hc). The reference is detached, so a currently-better cell gets zero direct error-term gradient; a worse real cell is pushed toward fewer positive decisions and a worse fake cell toward fewer negatives. This does NOT prevent conflicting gradients from other objectives or later model-wide shifts. Factor2 preserves the legacy value under uniform priors/full contributor diversity; unequal priors/support change the scale, intentionally and visibly. No loss weight is tuned after validation. The soft tail surrogate still differs from hard FPR/FNR; equality of soft means is not a general hard-tail guarantee. Tests include equal raw means/unequal hard tails and response-offset cancellation, but one fixture cannot prove equivalence.

The total remains weighted original BCE +0.1(original sensitivity+0.5original control)+I_aux×4×[0.1L_upper+0.1(aux sensitivity+0.5aux control)+0.1a_epoch L_alignment]. Response remains asinh(z_treated−z_sham), margin0.5. Global/local predictions, learned image/patch gates, positive fusion and signed local contributions are unchanged. Maps are not forgery masks and gates are not proven reliability estimates. Architecture stays21,594,159total/7,575,591trainable, exit-block tuning, frozen BN buffers.
